# Client email — Clone2GHL v1.0.5 Chrome Web Store submission

**Attachments to include when you send this:**
1. `extension/dist/clone2ghl-chrome.zip`  — the final package to upload
2. `Clone2GHL_v1.0.5_Submission_Guide.pdf`  — the step-by-step reference

---

**Subject:** Clone2GHL v1.0.5 — ready to submit to the Chrome Web Store (files attached)

---

Hi [Client name],

Good news — the **Clone2GHL v1.0.5** update is built, fully tested, and ready for you to submit to the Chrome Web Store.

I've attached two files:

- **`clone2ghl-chrome.zip`** — the final extension package to upload (version 1.0.5).
- **`Clone2GHL_v1.0.5_Submission_Guide.pdf`** — a short, step-by-step guide for the upload.

This is an update to your existing published extension, so it's quick — about **3 minutes**:

1. Open your **Chrome Web Store Developer Dashboard** and select the **Clone2GHL** item.
2. Go to **Package → Upload new package** and choose the attached **`clone2ghl-chrome.zip`**.
3. Paste the short **"What's new"** note (it's in the PDF), then click **Submit for review**.

Google usually reviews updates within **1–3 business days**. The production backend is already live, so the new version works the moment Google approves it. You won't need to change anything on the privacy or permissions screens.

**What's improved in v1.0.5:** a much simpler one-step Welcome / Activate screen (email + code + password), a guided "Getting Started" checklist, and a built-in Help & Guide — all designed to get new users to their first clone faster.

On my side I also fixed a packaging issue that could have caused Chrome to reject the upload, removed an unused permission, and ran a full security and Chrome-policy check — **no issues found**. The details are in the attached PDF if you'd like them.

Once Google approves, I'd suggest **one quick test purchase per plan** to confirm the full flow end-to-end, and then we're ready to announce.

Happy to jump on a quick call if anything comes up during the upload.

Best,
[Your name]
